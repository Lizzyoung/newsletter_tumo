OpenAI, 5/27 서울에서 ‘한국 사이버 액션 플랜’ 발표
— 한국·일본, 미국·캐나다에 이어 GTAC 아시아 첫 참여

📍 한 줄 요약

OpenAI는 5/27 서울 기자간담회에서 한국 정부·공공기관·기업이 OpenAI의 사이버 방어 프로그램에 참여하는 Korea Cyber Action Plan을 발표했다. 핵심은 한국이 일본과 함께 OpenAI의 정부·공공기관용 사이버 신뢰 접근 트랙인 GTAC에 합류하고, KISA가 한국 내 실무 운영을 맡는다는 점이다.

💡 쉽게 풀면

OpenAI의 Daybreak는 사이버 방어자가 취약점 탐지, 패치 검증, 위협 모델링, 보안 코드 리뷰를 더 빠르게 수행하도록 돕는 사이버 보안 이니셔티브다. OpenAI 공식 문서 기준으로 Daybreak는 GPT-5.5, GPT-5.5 with Trusted Access for Cyber, GPT-5.5-Cyber처럼 접근 수준을 나눠 운영한다.

이번 발표의 한국적 의미는 “모델 공개”보다 접근 권한의 제도화에 있다. GPT-5.5-Cyber는 일반 공개 모델이 아니라, 검증된 방어자와 기관이 승인된 환경에서 쓰는 제한 접근 모델이다. 한국 기관이 GTAC에 합류하면 공공 사이버 방어 업무에서 OpenAI의 사이버 특화 모델을 활용할 통로가 열린다.

다만 “한국 정부 전체가 즉시 GPT-5.5-Cyber를 쓴다”로 읽으면 과하다. 실제 접근 대상, 승인 절차, 예산, 사용 범위, 데이터 처리 조건은 아직 공개되지 않았다. 현재 확인된 것은 OpenAI 측 발표와 현장 브리핑 보도 기준의 참여 방향이다.

📊 확인된 핵심 사실

항목 내용
발표 2026/05/27 서울 JW 메리어트 호텔 기자간담회에서 OpenAI CSO Jason Kwon이 Korea Cyber Action Plan 발표.
정부 트랙 한국·일본이 미국·캐나다에 이어 OpenAI의 정부·공공기관용 사이버 신뢰 접근 트랙(GTAC)에 합류. 아시아 첫 사례로 보도됨.
모델 접근 참여 기관은 GPT-5.5-Cyber 등 사이버 특화 모델 접근 권한을 얻는 것으로 보도. OpenAI 공식 문서상 GPT-5.5-Cyber는 전문·승인 워크플로우를 위한 제한 프리뷰 모델.
한국 운영 KISA가 한국 내 프로그램 실무 운영을 맡는 것으로 보도. 다만 부처 간 역할 분담, 기관별 권한 등급, 계약 구조는 미공개.
민간 트랙 OpenAI는 한국 주요 기업과 민간용 TAC 확대를 논의 중이라고 밝혔다. 참여 기업명·규모·요금 조건은 공개되지 않음.
미래 모델 Kwon CSO는 향후 GPT-5.6·GPT-6 등 더 최신 사이버 역량도 신뢰된 방어자에게 빠르게 제공하는 방향을 언급한 것으로 보도됨.
✅ 왜 중요한가
  • 공공 사이버 보안 AI 도입의 기준점이 생긴다. 공공기관이 사이버 특화 모델을 도입할 때 “모델 성능”뿐 아니라 승인 절차, 사용 통제, 로그·감사, 데이터 처리 조건까지 함께 물을 가능성이 커진다.
  • 평가 기준이 모델 중심에서 워크플로우 중심으로 이동한다. OpenAI 공식 Daybreak 문서는 취약점 탐지, 패치 검증, 감사 가능한 증거, 개발 루프 내 보안 적용을 강조한다. 평가도 단순 정답률보다 “방어 업무를 실제로 얼마나 안전하게 수행했는가”로 옮겨간다.
  • Anthropic Glasswing과 비교 구도가 만들어진다. 한국이 OpenAI GTAC에 들어가면서, 향후 공공·금융권은 OpenAI 계열과 Anthropic 계열의 사이버 모델을 같은 기준으로 비교해야 하는 상황을 맞을 수 있다.
⚠️ 한계와 표현 주의
  • GTAC의 정확한 영문 풀이는 매체별로 다르게 표기됐다. 본문에서는 ‘정부·공공기관용 사이버 신뢰 접근 트랙’으로 풀어 설명했다.
  • OpenAI 공식 영문 사이트에는 본 호 작성 시점 기준 별도 Korea Cyber Action Plan 포스트가 확인되지 않았다. Korea-specific 세부 내용은 현장 브리핑 보도에 의존한다.
  • GPT-5.5-Cyber의 한국 내 실제 사용 범위·기관 명단·예산·성능 메트릭은 미공개다. “접근권 부여”와 “즉시 전면 도입”은 구분해야 한다.
  • KISA가 실무 운영을 맡는다는 보도는 확인되지만, KISA가 모든 평가 기준을 단독으로 정한다는 의미는 아니다. 과기정통부·국정원·K-AISI 등과의 역할 분담은 추가 확인이 필요하다.
🎯 Datumo 관점에서의 맥락

이번 발표의 핵심은 한국 공공기관이 사이버 특화 AI 모델을 다루는 과정에서 “승인된 접근, 안전한 사용, 검증 가능한 산출물”을 요구하게 될 가능성이 커졌다는 점이다. Datumo 입장에서는 단순 모델 성능 평가보다, 공공·금융권이 바로 쓸 수 있는 사이버 AI 평가 패키지를 먼저 정리하는 것이 중요하다.

우선순위는 두 가지다. 첫째, KISA·과기정통부의 AI 보안 요구사항과 Datumo 평가 산출물을 연결한 매핑표를 준비해야 한다. KISA와 과기정통부가 발간한 AI 보안 안내서는 개발자·서비스 제공자·이용자 관점의 보안 요구사항을 제시하고 있어, 공공 RFP에서 참조될 가능성이 높다.

둘째, OpenAI GPT-5.5-Cyber 계열과 Anthropic Glasswing/Mythos 계열, 국내 보안 모델을 같은 기준으로 비교할 수 있는 벤더 중립형 평가 리포트가 필요하다. 앞으로 고객이 묻는 질문은 “어느 모델이 더 똑똑한가”가 아니라 “우리 조직의 보안 업무에서 어떤 모델을, 어떤 통제 아래, 어떤 근거로 써도 되는가”가 될 가능성이 크다.

따라서 Datumo의 포지션은 한국 공공·금융 도메인에 맞는 사이버 AI 검증 레이어다. 모델 접근권이 열릴수록 평가 회사의 역할은 줄어드는 것이 아니라, 오히려 도입 전후의 리스크를 설명하고 감사 가능한 산출물로 남기는 쪽에서 더 중요해진다.
